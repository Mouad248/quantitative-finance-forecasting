Methodology

The cross_sectional_momentum strategy generates signals. Portfolio construction uses allocator inverse_volatility, rebalance cadence monthly, maximum leverage 1.50x, annual volatility target 12.00% over 63 observations, maximum absolute weight 60.00%, maximum gross exposure 1.00. Execution costs use commission 2.0 bps of traded notional and a 3.0 bps full quoted spread (half charged when crossing), and constant slippage 2.0 bps. Execution timing: decisions filled at the same bar's own close (a backtest-only idealization, not causally realizable live).. Weights are shifted by one observation before earning returns. This report contains full-sample statistics only; no out-of-sample evidence is attached. Run `quantlab walk-forward`, or configure a chronological holdout with a non-zero test ratio, before drawing out-of-sample conclusions.
